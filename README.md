# Pharmacy Upsell Matrix Generator

**Python Version:** 3.10+ | **Dependencies:** pandas, openpyxl | **License:** MIT

Скрипт на Python, который автоматически собирает базу сопутствующих товаров (допродаж) для аптечной сети. Он делает за пару секунд работу, которую категорийные менеджеры вручную в Excel собирали бы неделями.

## ❓ Какую проблему решает
Обычно в аптеках есть два списка: огромная номенклатура товаров и правила (например: «к группе Витамин С допродавать цинк, маски или антисептик»). 
Чтобы составить итоговую таблицу, где для *каждого* лекарства прописаны *все* его допродажи, менеджеры мучаются с ВПР (VLOOKUP) или сложными макросами, которые зависают на больших объемах данных.

Этот скрипт полностью автоматизирует процесс с помощью библиотеки `pandas`.

## 🛠 Как это работает
На вход подается один файл Excel с двумя листами:
1. **Препараты** (Код, Наименование, Подкатегория).
2. **Правила допродаж** (Подкатегория, Допродажа. Код, Допродажа. Наименование).

Скрипт моментально связывает товары по категориям и генерирует итоговый Excel-файл из трех колонок: **препарат + допродажа + категория**.

## 💡 Особенности
* **Без тормозов и циклов:** Вместо медленных циклов `for` данные объединяются на уровне движка Pandas, что позволяет обрабатывать десятки тысяч строк за доли секунды.
* **Фильтр «сам себе»:** Скрипт проверяет названия и автоматически удаляет строки, где препарат предлагает допродать самого себя. Кассир на кассе не получит глупую подсказку.
* **Чистка скрытых пробелов:** Программа на лету удаляет невидимые пробелы в начале и конце категорий, из-за которых в Excel часто ломаются формулы.
* **Удаление дублей:** Если в исходных правилах допродажи случайно зафиксировались повторы, скрипт сам очистит их перед объединением.

## 📋 Требования к входному Excel-файлу

Скрипт ожидает на вход один файл `.xlsx`, содержащий строго два листа в следующем формате:

### Лист 1: Номенклатура (Самый первый лист в книге)
Содержит справочник товаров аптеки. Обязательно наличие двух колонок:
* **`Наименование`** — точное название лекарства или товара (например, *Аевит капс. N10*).
* **`Подкатегория`** — терапевтическая группа, к которой относится товар (например, *Поливитамины*).

### Лист 2: Правила допродаж (Второй лист в книге)
Содержит логику рекомендаций. Обязательно наличие двух колонок:
* **`Подкатегория`** — группа, для которой действует правило (должна совпадать по названию с Листом 1).
* **`Допродажа. Наименование`** — конкретный товар, который кассовая система предложит купить в дополнение.

> 💡 **Важно:** Названия колонок чувствительны к регистру. Скрытые пробелы по краям строк и категорий скрипт зачистит автоматически. Полностью пустые строки будут отфильтрованы и проигнорированы.


## 📦 Установка и запуск

1. Скачайте проект с GitHub и откройте терминал в папке проекта.
2. Установите все зависимости одной командой (версии библиотек зафиксированы):
   ```bash
   pip install -r requirements.txt
   ```
3. Положите ваши рабочие файлы Excel с выгрузками аптеки (например, `аптека_май.xlsx`) в созданную папку `Входные_данные/`.
4. Запустите скрипт:
   ```bash
   python main.py
   ```
5. Программа выведет список всех найденных файлов в папке `Входные_данные/`. Введите номер нужного файла и нажмите **Enter**.

## 📊 Результаты работы

После обработки скрипт создаст папку `Результаты/`, куда сохранит файлы со штампом даты и времени в названии:
* **Основная матрица:** `Результат_ГГГГ-ММ-ДД_ЧЧ-ММ-СС.xlsx` — идеально чистые пары "препарат + допродажа" с ровными колонками шириной 40 символов.
* **Консольная статистика:** Если допродажи отсутствуют менее чем у 10 препаратов, их список выведется прямо в терминал.
* **Отчет об ошибках:** Если "сирот" окажется больше 10, программа автоматически создаст отдельный файл `Препараты_без_допродаж_...xlsx` (также с шириной колонок 40), чтобы категорийный менеджер мог быстро назначить сопутствующие товары.

> 💡 **Для быстрой проверки:** В папке `tests/` подготовлен демонстрационный файл `demo_data.xlsx`. Скопируйте его в созданную папку `Входные_данные/` и запустите скрипт, чтобы сразу увидеть программу в действии.
